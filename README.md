# Kotlin Exercises

**Building a solid foundation in Kotlin through problem solving.**

This repository documents my Kotlin practice through programming exercises. My goal is to strengthen my problem-solving skills, explore the language's features, and learn to write clearer, better-organized solutions.

🚧 **Work in progress:** exercises will be added as I advance in my studies.

## Why this project?

Learning a language goes beyond understanding its syntax. I use this project to practice analyzing problems, translating requirements into code, and explaining the decisions behind each solution.

For anyone exploring my portfolio, this repository aims to make my progress visible through code, documentation, and increasingly challenging exercises.

## Planned topics

| Topic | Exercise focus |
| --- | --- |
| Fundamentals | Variables, types, operators, and string manipulation |
| Control flow | Conditionals, loops, and logic challenges |
| Functions | Breaking down problems, parameters, and code reuse |
| Null safety | Handling nullable values and using Kotlin's safety features effectively |
| Collections | Lists, sets, maps, and transformation and filtering operations |
| Object-oriented programming | Classes, encapsulation, interfaces, and problem modeling |
| Kotlin features | Data classes, extension functions, and lambda expressions |

These topics outline my learning plan. Implementations will be added as the project develops.

## Exercise format

Each solution is planned to include:

- **Problem statement:** the challenge and expected behavior.
- **Kotlin solution:** the code written to solve the challenge.
- **Examples:** sample inputs and outputs to illustrate the result.
- **Learning notes:** concepts practiced and relevant decisions, where helpful.
