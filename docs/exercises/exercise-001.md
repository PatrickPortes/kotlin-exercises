# Exercise 001 - Hello World

## Statement
Create a Kotlin project and prepare it to organize and run the following exercises.
Display a Hello World message in the console.

## Source code
[HelloWorld.kt](../../src/exercises/fundamentals/ex001/HelloWorld.kt)

## How to run
Open HelloWorld.kt and run its main function.

## Example

Output:
```text
Hello World!!!
```

  <li align="justify">
    This exercise began by organizing the project structure in IntelliJ IDEA,

  </li>
  <br>
