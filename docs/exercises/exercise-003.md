# Exercise 003 - Sum Of Two Numbers

## Statement
Read two numeric values, calculate their sum, and display the result.

## Source code
[SumOfTwoNumbers.kt](../../src/exercises/arithmetic/ex003/SumOfTwoNumbers.kt)

## How to run
Open SumOfTwoNumbers.kt and run its main function.

## Example

Input:
5
3

Output:
The sum of the two numbers entered is: 8.

## Notes
- Learning concepts: console input with `readln()`, conversion from `String` to `Int` with `toInt()`, explicit type declarations, read-only variables with `val`, integer addition with `+`, string interpolation, and console output with `println()`.
