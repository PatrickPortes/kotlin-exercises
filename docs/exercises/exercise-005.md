# Exercise 005 - Predecessor and Successor

## Statement
Ask for an integer and display the integers immediately before and after it.

## Source code
[PredecessorAndSuccessor.kt](../../src/exercises/arithmetic/ex005/PredecessorAndSuccessor.kt)

## How to run
Open PredecessorAndSuccessor.kt and run its main function.

## Example

Input:
10

Output:
The Predecessor of 10 is 9
The Successor of 10 is 11

## Notes
- Learning concepts: trimming surrounding whitespace with `trim()`, safe integer conversion with `toIntOrNull()`, nullable values and null checks, conditional statements with `if`, early returns, smart casts after null validation, integer arithmetic with `+` and `-`, and string interpolation.
