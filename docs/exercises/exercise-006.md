# Exercise 006 - Double Triple and Square Root

## Statement
Read a numeric value and display twice its value, three times its value, and its square root.

## Source code
[DoubleTripleAndSquareRoot.kt](../../src/exercises/arithmetic/ex006/DoubleTripleAndSquareRoot.kt)

## How to run
Open DoubleTripleAndSquareRoot.kt and run its main function.

## Example

Input:
9

Output:
The twice of your number: 18
The triple of your number: 27
The square root of your number: 3.0

## Notes
- Learning concepts: multiplication with `*`, conversion from `Double` to `Int` with `toInt()` and truncation toward zero rather than rounding, importing functions from `kotlin.math`, square roots with `sqrt()`, formatting decimal output with `String.format()` and format specifiers such as `%.1f`, locale-dependent decimal separators, and `NaN` as a floating-point result.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, `Double` values, whitespace trimming, safe conversion with `toDoubleOrNull()`, null checks, conditional validation, early returns, smart casts, and string templates containing expressions.
