# Exercise 006 - Double Triple and Square Root

## Statement
Read a numeric value and display twice its value, three times its value, and its square root.

## Source code
[DoubleTripleAndSquareRoot.kt](../../src/exercises/arithmetic/ex006/DoubleTripleAndSquareRoot.kt)

## How to run
Open DoubleTripleAndSquareRoot.kt and run its main function.

## Example

Input:
9

Output:
The twice of your number: 18
The triple of your number: 27
The square root of your number: 3.0

## Notes
- Learning concepts: decimal values with `Double`, safe numeric conversion with `toDoubleOrNull()`, null validation and early returns, multiplication with `*`, conversion from `Double` to `Int` and loss of the fractional part, importing mathematical functions from `kotlin.math`, square roots with `sqrt()`, formatting decimal output with `String.format()`, locale-dependent decimal separators, and `NaN` as a floating-point result.
