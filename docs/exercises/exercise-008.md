# Exercise 008 - Meters to Centimeters and Millimeters

## Statement
Read a distance in meters and display its equivalent values in centimeters and millimeters.

## Source code
[MetersToCentimetersAndMillimeters.kt](../../src/exercises/arithmetic/ex008/MetersToCentimetersAndMillimeters.kt)

## How to run
Open MetersToCentimetersAndMillimeters.kt and run its main function.

## Example

Input:
1.5

Output:
1.5 meters distance is equivalent to 150.0 centimeters
1.5 meters distance is equivalent to 1500.0 millimeters

## Notes
- Learning concepts: decimal input and arithmetic with `Double`, safe conversion with `toDoubleOrNull()`, null checks, finite-number validation with `isFinite()`, non-negative value checks with comparison operators, combining validation conditions with `||`, early returns, metric unit conversion through multiplication, and string interpolation.
