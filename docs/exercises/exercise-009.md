# Exercise 009 - Multiplication Table

## Statement
Ask for an integer and display its multiplication table from 1 to 10.

## Source code
[MultiplicationTable.kt](../../src/exercises/arithmetic/ex009/MultiplicationTable.kt)

## How to run
Open MultiplicationTable.kt and run its main function.

## Example

Input:
5

Output:
The multiplication table for 5 from 1 to 10 is:
-----------
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
-----------

## Notes
- Learning concepts: console input, whitespace trimming, safe integer conversion, null checks and early returns, multiplication with `times()` and its equivalent `*` operator, expressions inside string templates with `${...}`, console output formatting, and recognizing repeated statements as an opportunity for future refactoring.
