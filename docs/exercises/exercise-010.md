# Exercise 010 - Reais to Dollars

## Statement
Read an amount in Brazilian reais and determine how many US dollars it can buy.

## Source code
[ReaisToDollars.kt](../../src/exercises/conversions/ex010/ReaisToDollars.kt)

## How to run
Open ReaisToDollars.kt and run its main function.

## Example

Input:
10

Output:
The converted amount is 50.0 US dollars.
