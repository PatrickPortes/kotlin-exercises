# Exercise 011 - Wall Area and Paint Required

## Statement
Ask for a wall's width and height in meters. Display its area and the amount of paint required, assuming each liter covers 2 square meters.

## Source code
[WallAreaAndPaintRequired.kt](../../src/exercises/arithmetic/ex011/WallAreaAndPaintRequired.kt)

## How to run
Open WallAreaAndPaintRequired.kt and run its main function.

## Example

Input:
4
3

Output:
The wall's area is 12.0 m², and you need 6.0 liters of paint.

## Notes
- Learning concepts: rectangular area calculations from width and height, and relating an area to material coverage expressed in square meters per liter.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, decimal values, whitespace trimming, safe numeric conversion, null checks, Boolean OR and short-circuit evaluation, conditional validation, early returns, smart casts, multiplication, division, and string interpolation.
