# Exercise 011 - Wall Area and Paint Required

## Statement
Ask for a wall's width and height in meters. Display its area and the amount of paint required, assuming each liter covers 2 square meters.

## Source code
[WallAreaAndPaintRequired.kt](../../src/exercises/arithmetic/ex011/WallAreaAndPaintRequired.kt)

## How to run
Open WallAreaAndPaintRequired.kt and run its main function.

## Example

Input:
4
3

Output:
The wall's area is 12.0 m², and you need 6.0 liters of paint.

## Notes
- Learning concepts: reading multiple decimal values, trimming console input, safe conversion with `toDoubleOrNull()`, combined null checks with `||`, early returns and smart casts after validation, rectangular area calculations, multiplication and division with `Double`, relating area to material coverage, and string interpolation with units of measurement.
