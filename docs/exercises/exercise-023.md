# Exercise 023 - Integer Digits

## Statement
Read an integer from 0 to 9999 and separately display its ones, tens, hundreds, and thousands digits.

## Source code
[IntegerDigits.kt](../../src/exercises/arithmetic/ex023/IntegerDigits.kt)

## How to run
Open IntegerDigits.kt and run its main function.

## Example

Input:
1234

Output:
Ones: 4
Tens: 3
Hundreds: 2
Thousands: 1

## Notes
- Learning concepts: integer division with `/`, remainders with `%`, decimal place values, and arithmetic digit extraction without converting the number to text.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, integer values, whitespace trimming, safe integer conversion, null checks, comparison operators and numeric bounds, Boolean OR and short-circuit evaluation, conditional validation, early returns, smart casts, parentheses, and string interpolation.
