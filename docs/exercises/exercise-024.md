# Exercise 024 - City Starts with New

## Statement
Ask for a city's name and report whether it starts with “New”.

## Source code
[CityStartsWithNew.kt](../../src/exercises/strings/ex024/CityStartsWithNew.kt)

## How to run
Open CityStartsWithNew.kt and run its main function.

## Example

Input:
New York

Output:
Your city name starts with 'New'.

## Notes
- Learning concepts: case-insensitive string comparison with `equals(..., ignoreCase = true)` and named arguments for function calls.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, strings, read-only variables, type inference, whitespace trimming, blank-string checks, early returns, lambdas, whitespace predicates, Boolean negation, extracting the first word with `takeWhile`, and conditional branching with `if` and `else`.
