# Exercise 025 - Name Contains Silva

## Statement
Read a person's full name and report whether it contains “Silva”.

## Source code
[NameContainsSilva.kt](../../src/exercises/strings/ex025/NameContainsSilva.kt)

## How to run
Open NameContainsSilva.kt and run its main function.

## Example

Input:
Ana Silva

Output:
Your Name Contains 'Silva'.

## Notes
- Learning concepts: searching for a substring with `contains()`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, strings, read-only variables, type inference, whitespace trimming, blank-string checks, early returns, case-insensitive text operations with `ignoreCase = true`, named arguments, and conditional branching with `if` and `else`.
