# Exercise 026 - Letter A Occurrences

## Statement
Ask for a sentence. Display how many times the letter “A” appears, the position of its first occurrence, and the position of its last occurrence.

## Source code
[LetterAOccurrences.kt](../../src/exercises/strings/ex026/LetterAOccurrences.kt)

## How to run
Open LetterAOccurrences.kt and run its main function.

## Example

Input:
A casa

Output:
Number of occurrences of the letter A: 3
Position of the first occurrence: 1
Position of the last occurrence: 6

## Notes
- Learning concepts: locating the first and last character occurrences with `indexOf()` and `lastIndexOf()`, zero-based string indexing, the `-1` result for a missing character, and converting indices to one-based positions for display.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, strings, read-only variables, type inference, whitespace trimming, blank-string checks, early returns, counting characters with `count`, lambdas and character predicates, case-insensitive equality checks, named arguments, comparison operators, addition, conditional branching, and expressions inside string templates.
