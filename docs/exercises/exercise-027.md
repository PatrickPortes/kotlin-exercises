# Exercise 027 - First and Last Names

## Statement
Read a full name and display the first and last names separately.

## Source code
[FirstAndLastNames.kt](../../src/exercises/strings/ex027/FirstAndLastNames.kt)

## How to run
Open FirstAndLastNames.kt and run its main function.

## Example

Input:
Patrick Portes

Output:
Your first name is Patrick, and your last name is Portes

## Notes
- Learning concepts: extracting a trailing sequence of characters with `takeLastWhile()`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, strings, read-only variables, type inference, whitespace trimming, blank-string checks, conditional validation, early returns, lambdas and the implicit `it` parameter, whitespace detection with `isWhitespace()`, Boolean negation, extracting the first word with `takeWhile`, and string interpolation.
