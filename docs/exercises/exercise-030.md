# Exercise 030 - Even or Odd

## Statement
Ask for an integer and report whether it is even or odd.

## Source code
[EvenOrOdd.kt](../../src/exercises/conditionals/ex030/EvenOrOdd.kt)

## How to run
Open EvenOrOdd.kt and run its main function.

## Example

Input:
8

Output:
The number is even.

## Notes
- Learning concepts: integer parity and divisibility by 2 as a criterion for distinguishing even and odd numbers.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe numeric conversion, null checks, conditional validation, early returns, smart casts, integer values, the remainder operator, equality checks, and conditional branching with `if` and `else`.
