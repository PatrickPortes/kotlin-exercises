# Exercise 032 - Leap Year

## Statement
Ask for a year and report whether it is a leap year.

## Source code
[LeapYear.kt](../../src/exercises/conditionals/ex032/LeapYear.kt)

## How to run
Open LeapYear.kt and run its main function.

## Example

Input:
2000

Output:
2000 is a leap year.

## Notes
- Learning concepts: Gregorian leap-year rules, century exceptions and the 400-year rule, and inequality checks with `!=`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe numeric conversion, null checks, conditional validation, early returns, smart casts, integer values, positive-value checks, comparisons, remainder-based divisibility checks, equality checks, Boolean AND and OR, parentheses, conditional branching, and string interpolation.
