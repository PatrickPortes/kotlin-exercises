# Exercise 033 - Largest and Smallest Values

## Statement
Read three numeric values and display the largest and smallest values.

## Source code
[LargestAndSmallestValues.kt](../../src/exercises/conditionals/ex033/LargestAndSmallestValues.kt)

## How to run
Open LargestAndSmallestValues.kt and run its main function.

## Example

Input:
4
9
2

Output:
Largest value: 9.0
Smallest value: 2.0

## Notes
- Learning concepts: finding the largest and smallest of multiple values with `maxOf()` and `minOf()`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe numeric conversion, null checks, conditional validation, early returns, smart casts, decimal values, combined null checks, Boolean OR and short-circuit evaluation, and string interpolation.
