# Exercise 034 - Salary Raise by Range

## Statement
Ask for an employee's salary and determine the raise amount. Apply 10% to salaries above BRL 1,250.00 and 15% to salaries equal to or below that amount.

## Source code
[SalaryRaiseByRange.kt](../../src/exercises/conditionals/ex034/SalaryRaiseByRange.kt)

## How to run
Open SalaryRaiseByRange.kt and run its main function.

## Example

Input:
1500

Output:
Your new salary is: 1650.0
