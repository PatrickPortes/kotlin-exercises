# Exercise 035 - Triangle Feasibility

## Statement
Read the lengths of three line segments and report whether they can form a triangle.

## Source code
[TriangleFeasibility.kt](../../src/exercises/conditionals/ex035/TriangleFeasibility.kt)

## How to run
Open TriangleFeasibility.kt and run its main function.

## Example

Input:
3
4
5

Output:
They can form a triangle!

## Notes
- Learning concepts: the triangle inequality and the requirement that each pair of side lengths must sum to more than the remaining side.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe numeric conversion, null checks, conditional validation, early returns, smart casts, decimal values, combined null checks, finite-number checks, positive-value constraints, comparisons, Boolean AND and OR, short-circuit evaluation, addition, and conditional branching.
