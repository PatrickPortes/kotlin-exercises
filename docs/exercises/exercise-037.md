# Exercise 037 - Number Base Conversion

## Statement
Read an integer and ask for the desired base: option 1 for binary, 2 for octal, and 3 for hexadecimal. Display the number converted to the selected base.

## Source code
[NumberBaseConversion.kt](../../src/exercises/conditionals/ex037/NumberBaseConversion.kt)

## How to run
Open NumberBaseConversion.kt and run its main function.

## Example

Input: 
31
3

Output: <br> 
Choose the target base: <br>
1 - Binary <br>
2 - Octal <br>
3 - Hexadecimal <br>  <br>
31 in base 16: 1F

## Notes
- Learning concepts: subject-based `when` expressions, matching menu choices to return values, binary, octal and hexadecimal number systems, and radix-based integer conversion with `toString(base)`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe numeric conversion, null checks, conditional validation, early returns, smart casts, integer values, alternative branches, early returns inside branches, string case conversion with `uppercase()`, and string interpolation.
