# Exercise 038 - Compare Two Integers

## Statement
Ask for two integers and report whether the first is larger, the second is larger, or both are equal.

## Source code
[CompareTwoIntegers.kt](../../src/exercises/conditionals/ex038/CompareTwoIntegers.kt)

## How to run
Open CompareTwoIntegers.kt and run its main function.

## Example

Input:
8
3

Output:
The first number (8) is larger.

## Notes
- Learning concepts: subjectless `when` statements with Boolean branch conditions evaluated in order.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe numeric conversion, null checks, conditional validation, early returns, smart casts, integer values, combined null checks, Boolean OR and short-circuit evaluation, comparison operators, alternative branches, and string interpolation.
