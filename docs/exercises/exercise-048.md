# Exercise 048 - Odd Multiples of Three Sum

## Statement
Calculate and display the sum of the integers from 1 to 500 that are both odd and multiples of three.

## Source code
[OddMultiplesOfThreeSum.kt](../../src/exercises/loops/ex048/OddMultiplesOfThreeSum.kt)

## How to run
Open OddMultiplesOfThreeSum.kt and run its main function.

## Example

Input:
No console input.

Output:
Sum of odd multiples of 3 from 1 to 500: 20667

## Notes
- Learning concepts: running totals with an accumulator initialized to zero, conditional accumulation inside a loop, and addition assignment with `+=`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console output, mutable variables, integer values, `for` loops, inclusive ranges, conditional statements, remainders, parity and divisibility checks, equality and inequality operators, Boolean AND, short-circuit evaluation, and string interpolation.
