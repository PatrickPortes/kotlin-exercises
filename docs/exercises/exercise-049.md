# Exercise 049 - Multiplication Table with For

## Statement
Redo exercise 009: ask for an integer and display its multiplication table from 1 to 10. This time, use a for loop.

## Source code
[MultiplicationTableWithFor.kt](../../src/exercises/loops/ex049/MultiplicationTableWithFor.kt)

## How to run
Open MultiplicationTableWithFor.kt and run its main function.

## Example

Input:
5

Output: <br>
The multiplication table for 5 from 1 to 10 is:
-----------
5 x 1 = 5 <br>
5 x 2 = 10 <br>
5 x 3 = 15 <br>
5 x 4 = 20 <br>
5 x 5 = 25 <br>
5 x 6 = 30 <br>
5 x 7 = 35 <br>
5 x 8 = 40 <br>
5 x 9 = 45 <br>
5 x 10 = 50
-----------

## Notes
- Learning concepts: the 64-bit `Long` integer type, conversion with `toLong()`, and widening an operand before multiplication to avoid overflowing an `Int` result.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only variables, type inference, whitespace trimming, safe integer conversion, null checks, conditional validation, early returns, smart casts, `for` loops, inclusive ranges, multiplication tables, replacing repeated statements with iteration, and expressions inside string templates.
