# Exercise 050 - Even Number Sum

## Statement
Ask for six integers and display the sum of only the even values. Ignore odd values when calculating the sum.

## Source code
[EvenNumberSum.kt](../../src/exercises/loops/ex050/EvenNumberSum.kt)

## How to run
Open EvenNumberSum.kt and run its main function.

## Example

Input:
1
2
3
4
5
6

Output:
Sum of the even numbers: 12

## Notes
- Learning concepts: explicit `Long` literals with the `L` suffix, as in `0L`.<br><br>

- Reinforced concepts: `main()`, package declarations, block comments, console input and output, read-only and mutable variables, type inference, integer values, `Long` accumulators, whitespace trimming, safe integer conversion, null checks, early returns, smart casts, `for` loops, inclusive ranges, conditional accumulation, `+=`, remainders, even-number detection, and string interpolation.
